# Морской бой (Sea Battle)

Настольная игра для Windows с современным графическим интерфейсом на **Dear PyGui** и веб-клиентом для второго игрока со смартфона. Проект разработан как школьный индивидуальный проект по информатике.

---

## Основные возможности

- **Режимы игры**:
  - **Против бота**: 2 уровня сложности («Лёгкий» — случайный поиск, «Умный» — алгоритм Hunt & Target с добиванием кораблей по линии).
  - **Мультиплеер (ПК ↔ Смартфон)**: игра в реальном времени через веб-страницу и открытый брокер MQTT (по QR-коду или 5-значному коду комнаты) без необходимости настраивать белый IP или локальную сеть.
- **Поддержка разных размеров поля**:
  - 8×8 (малый флот: 3, 2×2, 1×3)
  - 10×10 (классический флот: 4, 3×2, 2×3, 1×4)
  - 12×12 (большой флот: 5, 4, 3×2, 2×3, 1×4)
- **Удобная расстановка флота**:
  - Выбор палубности, поворот клавишей `R` или кнопкой, удаление любого корабля повторным кликом.
  - Быстрая автоматическая расстановка («Случайная расстановка»).
  - Наглядная валидация правил (запрет касания кораблей даже углами).
- **Интерфейс**:
  - Палитра в стиле Swiss Minimalism / Trust Blue по стандартам UI/UX Pro Max.
  - Окно победы и поражения с возможностью перезапуска в один клик.
  - Раздел «О проекте» с паспортом школьной работы, целями и описанием технологий.

## Быстрый запуск

### 1. Запуск готового EXE (Windows)
Готовый исполняемый файл находится в папке `dist/`:
```text
dist/SeaBattle.exe
```

### 2. Запуск из исходного кода Python
Требуется Python 3.10+ (Windows 10/11):

```powershell
# Установка зависимостей
pip install -r requirements.txt

# Запуск игры
python main.py
```

---

## Сборка EXE

Для повторной компиляции автономного `.exe` можно запустить батник `build_exe.bat` двойным кликом или выполнить:

```powershell
python build.py
```

Скрипт автоматически обновляет ассеты интерфейса и собирает один файл `dist/SeaBattle.exe` через PyInstaller.

```powershell

```

## Мультиплеер (Игра с телефона)

1. Файл `web/index.html` загружается на любой бесплатный HTTPS-хостинг (GitHub Pages, Vercel, Cloudflare Pages).
2. В приложении во вкладке **«Настройки»** указывается адрес вашей страницы.
3. Во вкладке **«Онлайн режим»** нажимается кнопка **«Создать комнату»**.
4. Второй игрок сканирует появившийся QR-код камерой телефона, расставляет флот в мобильном браузере и нажимает «Готов к бою».
5. Связь происходит через защищённый WebSocket MQTT брокер (`broker.hivemq.com` / `broker.emqx.io`).

## Структура проекта

```text
seabattle_game/
├── assets/ui/          # Сгенерированные иконки и текстуры кнопок меню
├── tests/              # Модульные тесты игровой логики и бота (pytest)
├── web/
│   └── index.html      # Мобильный веб-интерфейс для игры со смартфона
├── bot.py              # Искусственный интеллект бота (Hunt & Target)
├── build.py            # Скрипт сборки автономного Windows-приложения
├── build_exe.bat       # Быстрый запуск сборки в 1 клик
├── conftest.py         # Конфигурация для запуска тестов pytest
├── game_logic.py       # Механика морского боя, доски и кораблей
├── main.py             # Главное приложение Dear PyGui
├── make_ui_assets.py   # Генератор растровых текстур меню
├── network_relay.py    # Менеджер MQTT-синхронизации хоста
├── requirements.txt    # Зависимости проекта
└── theme.py            # Цветовая палитра, стили и шрифты
```
